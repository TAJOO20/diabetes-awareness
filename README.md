# diabetes-awareness
التوعية بمرض السكري تهدف إلى نشر المعرفة حول هذا المرض المزمن الذي يؤثر على قدرة الجسم على استخدام السكر في الدم بشكل صحيح. وتُعد التوعية خطوة أساسية لحماية الأفراد والمجتمع من مضاعفات المرض، من خلال تعزيز الفهم الصحيح لأسبابه، وأعراضه، وطرق الوقاية منه، وكيفية التعايش معه. 
الاسماء:
1/أحمد تاج السر سيد أحمد
2/رغد عثمان 
3/سجئ حريكة 
- شرح مختصر لما تم عمله في المعمل (خطوات العمل باختصار)
مثل:
- إنشاء Repository جديد على GitHub
- إضافة ملف README
- كتابة أسماء المجموعة وفكرة المشروع
- إنشاء ملفات Python وإضافة كود بسيط
- رفع الملفات باستخدام أوامر Git
